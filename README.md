# 曇心之境 Arcana Bloom

FFXIV 角色扮演占卜舖的官網。

**對著 `ArcanaBloom.html` 點兩下就能看**，不需要伺服器、不需要跑任何指令。

---

## 檔案在哪裡

```
ArcanaBloom.html            網頁骨架（只有結構，沒有內容）
css/style.css          全部的樣式

data/                  ★ 平常要改的內容，全都在這四個檔
  story.js             店家故事
  notice.js            占卜須知
  members.js           店員名單
  cards.js             牌組

images/                ★ 圖片
  members/             角色立繪
  cards/               牌面

js/                    程式碼，平常不用動
  config.js            ★ 輪播秒數、逆位開關等設定
  loader.js            解析文字格式、找圖的共用工具
  story.js  notice.js  members.js  cards.js  tarot.js  main.js
```

---

## 怎麼改內容

`data/` 裡的四個檔案雖然副檔名是 `.js`，但**內容是包在兩個 `` ` `` 之間的純文字**，
編輯的時候就當成在改記事本，不用管程式語法。

> ⚠️ 唯一的禁忌：文字裡不要出現 `` ` `` 這個符號（鍵盤左上角、數字 1 左邊那顆），
> 它會讓文字提前結束、整頁壞掉。中文引號「」、括號、驚嘆號都沒問題。

---

### 店家故事 `data/story.js`

用單獨一行 `---` 分成三段：

```
第一段：內文，空一行換一個段落（第一段會自動放大、加首字裝飾）
---
第二段：右邊資訊欄，一行一筆，格式「標籤：內容」
---
第三段：資訊欄下面的小字附註
```

### 占卜須知 `data/notice.js`

用單獨一行 `---` 分成兩段：

```
第一段：條目，空一行換一則
          第一行   ＝ 標題
          第二行起 ＝ 說明
---
第二段：最下面的小字附註，換行就是換行
```

### 店員 `data/members.js`

一位店員一段，長這樣：

```js
"1.員工1": `
名字
身分
自我介紹（空一行換段）
`,
```

- **引號裡的名字 ＝ 圖片檔名** → `images/members/1.員工1.png`
- **名字開頭的數字 ＝ 頁面順序**，想調順序就改數字（圖片檔名要跟著一起改）
- 自我介紹後面可以再加這兩行，不寫就不顯示：

```
英文名：Tiara La
引言：「牌不會替你決定，它只負責把話說難聽一點。」
```

新增一位店員 ＝ 複製一整段貼上、改名字和數字，再把圖丟進 `images/members/`。
刪除一位 ＝ 把那一段（含最後的逗號）整段刪掉。

### 卡牌 `data/cards.js`

一張牌一段：

```js
"愚者": `
卡牌名稱
卡牌關鍵字
卡牌敘述
卡牌解析
`,
```

- **引號裡的名字 ＝ 圖片檔名** → `images/cards/愚者.png`
- 解析後面可以再加這幾行，不寫就不顯示：

```
英文名：The Fool
編號：0
符號：♅              ← 沒有牌面圖時，正面顯示的符號
逆位關鍵字：魯莽　逃避　準備不足
逆位解析：你把「不想面對」誤認成「時候還沒到」。
```

**逆位是選用的**：有寫「逆位關鍵字／逆位解析」的牌才會隨機出現逆位；
沒寫的牌永遠正位，畫面上也不會出現正／逆位的標籤。
想一律關掉或一律打開，改 `js/config.js` 裡的 `tarot.reversed`。

## 圖片

| | 放哪裡 | 建議比例 |
|---|---|---|
| 店員立繪 | `images/members/` | 3:4 直式 |
| 牌面 | `images/cards/` | 5:8 直式 |

檔名要跟 `data/` 裡引號中的名字**一模一樣**。
副檔名 jpg / png / jpeg / webp / gif / avif 都可以，程式會自己找（依這個順序）。

> **請放 JPG，不要直接放遊戲截圖的 PNG。**
> 遊戲截圖存成 PNG 通常一張 4～5 MB，六張就把首頁撐到近 30 MB，手機要等很久。
> 同一張圖轉成 JPG（品質 85、寬度 1000px 左右）大約只有 200 KB，肉眼看不出差別。
> 現在站上這幾張已經轉好了，未壓縮的原圖收在 `images/_original/`，
> 那個資料夾已寫進 .gitignore，只留在你自己電腦上。

沒放圖也不會壞：
- 店員 → 顯示「角色立繪」佔位框，小頭像顯示名字第一個字
- 卡牌 → 改用「符號：」那一行的符號

> 圖片還沒放齊時，瀏覽器主控台（F12）會出現一些 `ERR_FILE_NOT_FOUND`，
> 那是程式在試副檔名，不影響畫面。圖放齊了就會消失。
> 想少幾則訊息，可以在 `data/` 的名字後面直接指定副檔名，例如 `"1.員工1|jpg"`。

## 小提醒

- `data/` 的四個檔請存成 **UTF-8**（VS Code 預設就是；記事本另存新檔時要選 UTF-8）。
- 每一行以 `#` 開頭的都是註解，不會顯示在網頁上。
- 某一區的內容寫壞時，只有那一區會顯示紅色錯誤訊息，其他三區照常運作。
- 傳到 GitHub Pages 或任何網站空間也一樣可以直接用，不用改任何東西。
